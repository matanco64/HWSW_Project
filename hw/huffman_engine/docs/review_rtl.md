### Cleared (checked, no finding)

- **err_set mapping** (brief item 4): verified index by index — `err_set = {ctrl_err[3](UNDERRUN)→bit15, ctrl_err[5](LIMIT)→14, ctrl_err[4](SYMBOL)→13, ctrl_err[2](SELECTOR)→12, ctrl_err[1](NOCODE)→11, ctrl_err[0](TABLE)→10, 1'b0(PARAM, regs-internal)→9}` matches MAS §4 exactly. huff_regs address map, ERR_PARAM ranges (SYMBOL_LIMIT 1..2^27, ALPHABET/N_TABLES per mode), latching, BRESP hold, lengths stride t·48, RMW bins, W1C/IRQ all conform (modulo R21).
- **C0→C1 symtab alignment**: the read register updates every cycle from the combinational `index_c0`, and `c1_v` is a strict 1-cycle shadow of `issue` — data and valid stay aligned; stalls cannot separate them (C1 is never held). The overflow (R1) is the only C1 pathology.
- **DEFLATE window remap direction** (top, lines 264-272): `dec_window[19-i] = window[5+i]` puts the first next bit at 19 — correct for the compare form given the aligner convention. The remap itself is right; R14 is about `u_dfl` bypassing it.
- **ERR_LIMIT drain semantics** (bzip2): `issued_cnt` gating + `limit_hit` on the LIMIT'th handshake reproduce uArch §2/N3 (exactly LIMIT beats, EOB-at-LIMIT → DONE); one-shot err pulses cannot overwrite each other.
- **Counters**: CYCLES doorbell-inclusive through DONE/ERR, SYMBOLS handshaken-live, BITS excludes skip and clamps on underrun, BUILD_CYCLES = alphabet+MAXLEN max — all per MAS (OVERFETCH excepted, R19).
- **N5 abort disposition timing**: `eob_sent` registers on the TLAST handshake edge; same-cycle abort resolves to DONE-wins as specified (the DRAIN *exit* bugs are R4/R5).
- **Yosys 0.68 subset**: packed localparam tables, no unpacked-localparam arrays, no fn-call bit-selects, memories 1-D — clean across the new files (R24/R25 aside).
- TB wrappers `huff_regs_tb_top`/`huff_build_tb_top`: wiring-only as documented, mirror the top's port hookup faithfully.
