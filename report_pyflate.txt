1. OVERVIEW
-----------
[TODO] pyflate is a pure-Python bzip2/DEFLATE decompressor (the shipped input
data/interpreter.tar.bz2 is bzip2, magic 0x425a). Pipeline per block:
RBitfield bit reader -> per-symbol Huffman decode (linear scan, tables
switched every 50 symbols via selectors) -> move-to-front -> run-length
decode -> inverse Burrows-Wheeler transform -> RLE4 expansion.
Libraries: stdlib only (pyperf harness). Data structures: Python big-int
bit buffer, list-based Huffman tables, lists for MTF/BWT.
Output is MD5-verified every run — built-in correctness oracle.

5. HARDWARE ACCELERATION PROPOSAL
---------------------------------
[TODO — full proposal per course rubric]
Primary design: fixed-function Huffman-decode engine (Intel IAA/QAT
analogue): DMA descriptor (bitstream addr + bit offset, code-length
tables, output buffer), barrel-shifter bit aligner -> canonical-code
comparator cascade -> symbol RAM, 1 symbol/cycle, FSM table swap per
50-symbol group. Register map: CTRL, STATUS, SRC_ADDR, SRC_BITOFF,
TBL_ADDR, DST_ADDR, LEN, DOORBELL.
Secondary block: 256-entry move-to-front shift-register CAM (fused
pipeline stage). Verilog sources in hw/.
